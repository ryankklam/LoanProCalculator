# 不规则还款14 - 产品需求文档

## 概述
- **Summary**: 创建新的还款方案"不规则还款14"，该方案采用"利随本清"模式，即当有本金还款时，对应的分段利息也要一并归还
- **Purpose**: 提供更灵活的还款方式，满足用户在每次归还本金时同时结清对应期间利息的需求
- **Target Users**: 需要灵活安排本金还款并同步结清对应利息的贷款用户

## 目标
- 创建新的还款方案类型"IRREGULAR_REPAYMENT_14"
- 实现"利随本清"计算逻辑
- 保持与现有系统的兼容性
- 提供完整的中英文界面支持

## 非目标（Out of Scope）
- 不修改现有的还款方案逻辑
- 不添加新的配置参数（复用不规则还款5的配置）
- 不修改UI布局（仅添加新的还款方案选项）

## 背景与上下文
- 现有系统已支持"等额本息"和"不规则还款5"两种还款方案
- 不规则还款5的特点是：利息按固定频率归还，本金单独归还
- 不规则还款14的特点是：每次归还本金时，同时归还从上一次还款日到本次还款日期间的利息
- 系统已采用组合模式重构，便于添加新的还款方案

## 功能需求
- **FR-1**: 在RepaymentScheme枚举中添加IRREGULAR_REPAYMENT_14选项
- **FR-2**: 创建IrregularRepayment14Calculator类，实现"利随本清"计算逻辑
- **FR-3**: 在计算器工厂中注册新的还款方案
- **FR-4**: 在配置界面中添加"不规则还款14"选项
- **FR-5**: 添加中英文翻译支持

## 非功能需求
- **NFR-1**: 所有现有测试用例必须通过
- **NFR-2**: 计算精度必须与其他还款方案保持一致（小数点后2位）
- **NFR-3**: 新计算器必须复用现有的策略组件（日期、假期、利率等）

## 约束
- **技术**: TypeScript + React + date-fns
- **业务**: 必须复用现有的配置参数（利息还款频率、利息还款日等）
- **依赖**: 依赖现有策略组件（无需修改）

## 假设
- 利息还款频率和利息还款日配置同样适用于不规则还款14
- 节假日调整逻辑与其他还款方案保持一致
- 用户期望的"利随本清"是指：每次本金还款时，计算并归还从上一次付款日到本次付款日期间的利息

## 接受标准

### AC-1: 新还款方案可在配置界面选择
- **Given**: 用户打开贷款计算器
- **When**: 用户点击还款方案下拉菜单
- **Then**: 可以看到"不规则还款14"选项（中英文）
- **Verification**: `human-judgment`

### AC-2: 本金还款时同时归还对应利息
- **Given**: 用户选择不规则还款14方案
- **When**: 用户在某日期添加本金还款
- **Then**: 系统计算从上一次还款日到本次还款日的利息，并与本金一起归还
- **Verification**: `programmatic`

### AC-3: 利息付款日仍需归还利息（无本金时）
- **Given**: 用户选择不规则还款14方案，设置利息还款频率为月度
- **When**: 到达利息付款日且无本金还款
- **Then**: 系统归还从上一次还款日到本次利息付款日的利息
- **Verification**: `programmatic`

### AC-4: 贷款到期时结清剩余本金和利息
- **Given**: 用户选择不规则还款14方案
- **When**: 到达贷款到期日
- **Then**: 系统归还剩余本金和从上一次还款日到到期日的利息
- **Verification**: `programmatic`

### AC-5: 所有现有测试用例通过
- **Given**: 完成不规则还款14的开发
- **When**: 运行所有测试
- **Then**: 所有35个现有测试用例通过
- **Verification**: `programmatic`
